## JDK, JVM, JRE
The **Java Development Kit** (JDK) contains all the tools required to compile, debug, and execute a Java program. The version of the JDK represents a version of Java. 

Java compiles source code to an intermediate form known as **bytecode**.

The **Java Virtual Machine** (JVM) is where Java takes the bytecode, translates it into machine instructions, and executes it.

The **Java Runtime Environment** (JRE) contains the JVM as well as standard libraries needed to run Java programs.

## Terminology
### Expression
An expression is some code that evaluates to a single value. Example: `5 + 3`.

### Statement
A statement is a line of code that performs some action.

For example, variable assignment: `int x = 5;`. 

A statement can contain an expression: `int x = 5 + 3;`.

### Literal
A literal is a fixed value written directly into code: `1`, `"Hello"`, `true`, etc.
