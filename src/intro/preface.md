# Preface
This "textbook" is based on materials from the course textbook (*Introduction to Java Programming and Data Structures* by Daniel Liang) and the powerpoints from PF-I and PF-II.

## Java Version
The code examples uses syntax from **Java 25+**. Specifically, the simplification of the `main` function, printing, and reading input. 

One thing it does not use is the short-hand keyword for declaring variables: `var` and perhaps some other formatting-related syntax. Nonetheless, all code examples will still run on Java 25 and 26.

## Programming Fundamentals I
If you are coming from the Python section (or were allowed to skip PFI depending on transfer or other circumstances), I recommend you spend some extra time on the "Introduction" chapter.

## Running Code
The code examples here, the ones that give output at least, have an "Output" section directly under them. If you want to modify them, I suggest you use either your IDE or some online compiler **that supports Java 25** such as [OneCompiler](https://onecompiler.com/java).
